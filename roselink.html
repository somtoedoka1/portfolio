📄 Abstract

A significant Automation Gap persists in the modern enterprise landscape, particularly for small-to-medium organizations that depend heavily on legacy desktop software lacking modern API connectivity. Traditional automation solutions are largely ineffective in these closed-source, "API-Dark" environments.

RoseLink is an autonomous software agent engineered to interact with Graphical User Interfaces (GUIs) exactly as a human operator would. It utilizes a robust Vision-Language-Action (VLA) pipeline to perceive and navigate dynamic desktop environments, integrating LangGraph for resilient agentic orchestration, a multimodal LLM for a continuous vision-and-action loop, and Docker for secure, headless virtualization.

The resulting functional prototype acts as a digital bridge between unstructured modern data (such as PDF invoices) and antiquated local systems—providing a cost-effective alternative to expensive software overhauls.

⚠️ Problem Statement

Current automation solutions (traditional RPA, API-based triggers like Zapier) fall short when dealing with closed-source, desktop-bound software. These tools require rigid coordinate mapping or dedicated webhooks. The "Last Mile" of digital transformation remains bottlenecked by repetitive manual labor performed by skilled employees acting as human data-bridges.

Standard AI models offer excellent text-based assistance but lack the operational agency to physically execute labor on a local machine. RoseLink addresses this with a VLA pipeline capable of reliably navigating dynamic desktop environments without constant human supervision or custom API development.

🏗️ System Architecture

🤖 Agentic Orchestration

LangGraph maintains task state and handles complex, multi-step error-correction protocols via graph-based orchestration.

👁️ Vision & Action Loop

Real-time screen captures are passed to a multimodal LLM which perceives the desktop state and calculates exact OS input coordinates.

🐳 Virtualization Layer

Docker and headless virtual desktops (Xvfb / X11) provide isolated execution environments for secure, scalable agent operation.

🖥️ Frontend Dashboard

A Next.js application with WebSocket support allows users to upload documents and monitor the agent's VLA loop in real-time.

🔄 Vision-Language-Action Pipeline

1

Document Ingestion

User uploads an unstructured document (e.g., PDF invoice) via the Next.js dashboard. The backend extracts structured data fields.

2

Screen Capture & Preprocessing

A screenshot of the virtualized desktop is captured (<200ms) and preprocessed before being sent to the multimodal LLM.

3

Multimodal LLM Inference

The LLM performs zero-shot visual grounding — identifying UI elements and calculating exact click/type coordinates (<3s avg: 2.4s).

4

OS-Level Action Execution

The Open Interface framework translates the LLM's output into precise mouse movements and keyboard inputs (<100ms avg: 45ms).

5

Verification & Error Correction

LangGraph verifies action success. On failure, it routes to an error-correction node — scroll, zoom, or reassess — before retrying.

💻 Core Implementation

LangGraph node routing for the RoseLink VLA loop:

roselink/agent/nodes.py 
def execute_gui_action(state: AgentState):
    # Retrieve current screen capture and target action
    vision_context = get_screen_state()

    # Multimodal LLM determines exact UI coordinates
    coordinates = llm_vision_parse(
        vision_context,
        state.target_element
    )

    if coordinates:
        # Open Interface executes the OS-level action
        open_interface.click(coordinates.x, coordinates.y)
        return {"status": "success", "next_node": "verify_action"}
    else:
        return {"status": "element_not_found", "next_node": "error_correction"}


def error_correction(state: AgentState):
    # Scroll, zoom, or re-capture to recover from UI shift
    strategy = determine_recovery_strategy(state.last_error)
    apply_strategy(strategy)
    return {"next_node": "execute_gui_action", "retries": state.retries + 1}

🧪 Testing Strategy

Backend Unit Tests (Pytest)

LangGraph nodes and Open Interface wrappers tested with mocked LLM API responses. Covers timeouts, malformed JSON, and "element not found" errors without live API calls.

Frontend Unit Tests (Jest + RTL)

Next.js dashboard state updates verified against agent progress. File upload triggering the backend initialization sequence is explicitly tested.

E2E Integration Tests

Automated tests spin up a Docker container, launch a Tkinter dummy GUI, and dispatch the RoseLink agent to complete a full input sequence autonomously.

🚀 Future Work

  • Integrate smaller, locally hosted Vision-Language Models (VLMs) fine-tuned for GUI navigation to eliminate cloud latency and address data-privacy concerns for enterprises handling sensitive financial or medical records.
  • Transition inference from cloud-based APIs to local, dedicated GPU hardware — targeting sub-500ms visual grounding to surpass proficient human typing speed.
  • Expand Open Interface capabilities to support complex drag-and-drop mechanics, broadening the range of legacy software RoseLink can operate.
  • Develop a multi-tenant SaaS platform where concurrent agents operate in isolated Docker containers on a single host server without cursor conflict.
